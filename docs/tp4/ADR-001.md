# ADR-001 — Monolithe modulaire PHP 8 + PDO

## Contexte
Équipe de 3-4, 25 h, déploiement local Windows, données fictives.

## Décision
Monolithe modulaire PHP 8 avec PDO, sans framework.

## Conséquences
+ Démarrage rapide, peu de dépendances, requêtes préparées natives.
- Routage et validation écrits à la main, à tester manuellement.
